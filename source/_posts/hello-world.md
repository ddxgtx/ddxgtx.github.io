## 关于这个博客

这个博客使用 [Hexo](https://hexo.io/) 搭建，采用 [Butterfly](https://github.com/jerryc127/hexo-theme-butterfly) 主题。

## 快速开始

### 创建新文章

```bash
hexo new "文章标题"
```

### 本地预览

```bash
hexo server
```

### 生成静态文件

```bash
hexo generate
```

### 部署

```bash
hexo deploy
```
